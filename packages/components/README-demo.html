🐝 @bee-ui/core - Copy Buttons Demo

Installation

Copy this command to install the package:

npm install @bee-ui/core

Basic Usage

Copy this code to get started:

import '@bee-ui/core/styles.css';
import { Button, Input, Card } from '@bee-ui/core';

function App() {
  return (
    

      
      
      Content
    

  );
}

CLI Usage

Copy these commands to use the CLI tool:

# Install CLI globally
npm install -g @bee-ui/cli

# Initialize project
beeui init

# Add components
beeui add button input card

Tailwind Config

Copy this configuration for Tailwind CSS:

module.exports = {
  content: [
    './src/**/*.{js,ts,jsx,tsx}',
    './node_modules/@bee-ui/core/**/*.{js,ts,jsx,tsx}',
  ],
  theme: {
    extend: {
      colors: {
        primary: {
          500: '#6366f1',
        },
      },
    },
  },
  plugins: [],
};

How It Works

Hover over any code block above to see the copy button appear in the top-right corner. Click it to copy the code to your clipboard!

The copy button will show "Copied!" when successful, or "Failed" if there's an error.
